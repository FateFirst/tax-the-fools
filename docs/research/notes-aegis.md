## 1. Visual language

**Philosophy**: they ported a flat, dark, modern web mock (CSS custom properties) into 1.12. Every colour, font and texture is declared only in `Theme.lua`, and `Tools/verify.py:274-292` *fails the build* if shipped code references Blizzard chrome art (`Interface\DialogFrame`, `UI-CheckBox`, `UI-Panel-Button`, `UI-ScrollBar`, `Interface\Icons\`, quest and minimap art).

### Palette (`Theme.lua:30-51`, documented in `docs/UI_SPEC.md:16-31`)
```lua
local function hex(s) return { tonumber(string.sub(s,1,2),16)/255, ... } end   -- Theme.lua:22
Theme.color = {
  panel="202020"  -- window body        panel2="111111" -- header/footer strips, dropdown face, tooltip
  panel3="1a1a1a" -- inactive pills, sidebar   tabbg="3b3b3b" -- tab strips, nav rows, selected row
  accent="52c722" accentDeep="2e850e" accentGlow="8fe066"  -- green family (themeable)
  gold="ffed71" goldDeep="e8b93a"  danger="e8636b"  blue="5b9fd6"
  bandGreen="2e850e" bandRed="7c1820"
  text="ffffff" textDim="c7c7bd" border="050505" subtle="545454" switchOn="2e850e" }
```
- `Theme:Code(name)` (`Theme.lua:55`) returns a `|cffrrggbb` chat code for mixed-colour strings.
- **Themes** (`Theme.lua:74-97`): Day, Night, Turtle (default), OctoWoW, RavenCraft, Capybara and Aegis. Each theme overrides only the accent family and sometimes the panel shades. `Theme:ApplyTheme` (`:371`) mutates the colour tables in place, then re-tints every texture and font string from **weak-keyed records** (`tintName`, `textName`, `:314-334`). The result is live re-theming with no reload.
- Fixed semantic colours: `LEVEL_COLORS`, `CLASS_COLORS`, and `COIN_COLORS = { g={1,.82,0}, s={.78,.78,.81}, c={.78,.47,.25} }` (`:287-301`). Use these for money text.
- Hover and selection washes are **white at low alpha**: `text` at 0.03 (nav column bg), 0.04 (hover), 0.05-0.06 (HIGHLIGHT layer) and 0.08 (selected).

### Textures (all bundled; `media/README.md`)
- These are generated by `Tools/build/make_assets.py` (Pillow) as 32-bit RLE TGA files with power-of-two sizes and a bottom-left origin.
- **They are white masks, tinted at runtime with `SetVertexColor`.** One 32×32 rounded-rect serves every panel, tab and pill.
- Main textures:
  - `solid` (8×8): flat fills and dividers. This stands in for `SetColorTexture`.
  - `panel-fill` / `panel-border`: 32×32 nine-slice with a 10px radius.
  - `tab-fill` / `tab-border`: 6px radius.
  - `pill-*`, `circle-fill` / `circle-border`.
  - `cap-top` / `cap-bottom`: rounded on one edge only, for header and footer strips.
  - `shadow` (64×64): a ring with a 7px outset and a transparent middle.
  - `scroll-thumb`: stadium shape.
  - `switch-track`: 64×32 stadium.
  - `grip`: a six-dot resize grip.
  - `progress-fill`: gradient with the colour baked in.
  - `wordmark` (256×32): pre-rendered title. Font strings cannot letter-space.
  - `icons/*.tga`: 32×32 glyphs (`menu`, `close`, `plus`, `tick`, `caret-up/down`, `chevron`, `arrow`, `star`, `search`, `gear`, `dots`, `lock`, …), because the 1.12 font has no ✕ ☰ ✓ ‹ › glyphs (`Theme.glyph`, `Theme.lua:141-172`).
- Path constant: `local MEDIA = "Interface\\AddOns\\Aegis_Pathfinder\\media\\"` (`Theme.lua:14`).

### Fonts (`Theme.lua:221-226`, `:400-407`)
- `display` = Rajdhani-Bold, `display2` = Rajdhani-SemiBold, `body` = Inter-Regular, `body2` = Inter-SemiBold. All are bundled TTFs.
- `Theme:SetFont(fs, role, size, flags)` falls back to `STANDARD_TEXT_FONT` when `fs:SetFont` returns false. That return value is the only way to detect a rejected font on 1.12.
- Size scale in use:

| Size | Font | Used for |
|---|---|---|
| 9 | display | badge |
| 10 | display | subhead, uppercase |
| 11 | display | pill, tab and chip labels, uppercase |
| 12 | display | section header, accent, uppercase |
| 13 | display | header tabs |
| 18 | display | big totals and titles |
| 11 | body | fine print, rows |
| 12 | body | dropdown items, tooltip title |
| 13 | body | switch, checkbox and slider labels, nav rows |

- Uppercase is applied in code with `string.upper`.

### Borders, spacing, headers, close buttons
- **Panel** = shadow ring (BACKGROUND, black at 0.62) + fill nine-slice (BACKGROUND) + 1px border nine-slice (BORDER, `border` colour). See `Theme:Panel`, `Theme.lua:495-504`.
- **Header**: 30px high, inset 1px. It uses `CapStrip(panel2,"top")`, a 1px `Divider` under it and the wordmark centred at 128×16 (`Theme:Header`, `:980-1017`).
- **Subhead**: 18px `tabbg` strip with a divider and a 10px display uppercase label in `textDim`, inset 14px (`:1495-1511`). The header names the product; the subhead names the page, for example `CONFIG · GEAR` (`OptionsFrame.lua:1309`).
- **Close chip**: a 20px rounded square (`tabFill` with `text` at 0.04 alpha, plus a `tabBorder`) holding a 10px `close` glyph. It sits 8px from the header's right edge. Hover sets the fill to 0.10 and the glyph to white. It hides an explicit target, not its parent (`Theme:CloseChip` `:701`, `ChipButton` `:933-969`, placed in `Chrome` at `:1526-1527`).
- Options geometry (`OptionsFrame.lua:45-58`):
  - pane 396px wide; nav 150px; total height 560
  - header 30 and subhead 18, so `CHROME_TOP` = 48
  - padding: X 14, top 12, bottom 16
  - scrollbar width 10
  - section gap 16; header gap 7
  - nested-control indent (`SUB_INDENT`) 24
- Disabled or "held" controls render at **alpha 0.45** and are made unclickable.

## 2. Window/panel framework

- **Pure Lua `CreateFrame` throughout.** The only XML is `Bindings.xml` and a `<Script>` include list (`Crafting/Crafting.xml`). The only Blizzard templates used are `GameTooltipTemplate`, for hidden scan tooltips, and `CharacterFrameTabButtonTemplate`, for a tab on Blizzard's character frame.
- **One-call chrome**, `Theme:Chrome(frame, subtitle, onMoved)` (`Theme.lua:1522-1534`), does four things:
  - creates the header and makes it the drag handle
  - adds a close chip
  - adds an optional subhead
  - calls `RegisterWindow`
- A typical window, from `MaterialsFrame.lua:62-72`:
  ```lua
  local frame = CreateFrame("Frame", "AegisPathfinderMaterials", UIParent)
  frame:SetFrameStrata("DIALOG"); frame:SetWidth(WIDTH); frame:SetHeight(...)
  frame:SetPoint("CENTER", UIParent, "CENTER", 0, 0)
  Theme:Panel(frame, "panel"); frame:Hide()
  Theme:Chrome(frame, "Shopping list", Theme:PositionSaver("materialsframe"))
  ...
  table.insert(UISpecialFrames, "AegisPathfinderMaterials")   -- Escape closes
  ```
- **Movable**: `header:MakeDragHandle` (`Theme.lua:998-1014`) does `SetMovable`, `RegisterForDrag("LeftButton")`, `StartMoving` and `StopMovingOrSizing`. It then calls `Theme:AnchorTopLeft(frame)` (`:1868-1874`), which re-pins the frame with a single `TOPLEFT` anchor to `UIParent BOTTOMLEFT`. This works around the client re-anchoring a frame by whichever corner it likes.
- **Saved positions** (`Theme.lua:1879-1906`):
  - `PositionSaver(key)` stores `point`, `rel`, `x` and `y` in `db.profile`.
  - `RestorePosition(frame,key)` is called in `OnShow`. When nothing is saved, the window snaps beside the main window on whichever side faces screen centre (`OptionsFrame.lua:1242-1256`, `MaterialsFrame.lua:198-212`).
  - `/apg resetpanels` forgets them all.
- **Resizable**: there is no `StartSizing`. A custom 12-14px `grip` frame does the work (`OptionsFrame.lua:1186-1236`, `ObjectivesFrame.lua:183-251`):
  - `OnMouseDown` records the cursor position and size, then installs an `OnUpdate`.
  - The `OnUpdate` computes `w + dx` and `h - dy` from `GetCursorPosition()/GetEffectiveScale()`, and polls `IsMouseButtonDown` so a release outside the grip still ends the drag.
  - Size is clamped to min/max and the screen, then saved in `db.profile.optionswidth` / `optionsheight`.
  - Hover tints the grip accent; dragging tints it `accentGlow`.
- **Window stacking** (`Theme.lua:1699-1857`): every DIALOG window is registered. `BringToFront` rebuilds the frame levels of every open window's whole descendant tree into bands from base 10, with a gap of 4. This prevents two overlapping windows from interleaving their children. It runs on show (via a 1×1 child "watch" frame's `OnShow`, so it does not clobber the window's own `OnShow`) and on header mouse-down. It also sets `SetToplevel(true)` and `SetClampedToScreen(true)`.
- **Global window scale** (`Theme.lua:1764-1796`): every registered window gets `SetScale(windowScale * scaleFactor)`. The range is 0.6-1.5 in steps of 0.05, and it is set from a slider.
- **Fade-in** on open (`Theme:FadeIn`, `:1022-1035`): an alpha ramp in `OnUpdate`, 0.5s.
- **Tabs**:
  - `Theme:Tab` (`:713-743`) is the in-body tab. It uses a `tabFill` nine-slice: active is `panel` fill with accent text; inactive is `tabbg` fill with `textDim` text. Example: two half-width tabs in `MaterialsFrame.lua:74-87`.
  - Header tabs (`GuideListFrame.lua:151-180`) show uppercase display text with a 2px accent underline when active.
- **Side navigation** (`OptionsFrame.lua:1134-1181`, `GuideListFrame.lua:196-317`):
  - The nav is a 150px column with a `text` 0.03 background and a 1px right edge at `text` 0.08.
  - Each row is 30px. A selected row shows a 3px accent left bar, a 0.08 white fill and white text; hover shows a 0.04 fill.
  - Sub-pages are indented 28px (instead of 14) at font 12.
  - The guide browser's sidebar is `panel3` with a `CapStrip("bottom")` and a pinned "Options" row at the bottom above a divider.
- **Scroll frames**: two kinds, and **no FauxScrollFrame**.
  1. **Real `ScrollFrame` + scroll child** for variable-height content (options pages) (`OptionsFrame.lua:620-651`, `:1314-1329`):
     - The holder's height is set to the page's `contentHeight`.
     - `UpdateScrollChildRect()` is called after resizing.
     - The theme `ScrollBar` (a Slider) drives `SetVerticalScroll`.
     - The wheel works anywhere on the frame (`EnableMouseWheel` with steps of 40px).
     - The bar hides when the content fits.
  2. **Virtual list (offset + fixed row pool)** for long lists (`MaterialsFrame.lua:96-125, 255-292`; `CraftRouteFrame.lua:443-523`):
     - Create `MAX_ROWS` row frames once.
     - On update, compute `maxOffset = total - shown`, clamp `offset`, and set the slider's min/max and value under an `updating` guard flag so the update does not recurse.
     - Paint `list[i + offset]` into row i and hide unused rows.
     - The window height shrinks to fit `max(MIN_ROWS, min(MAX_ROWS, n))` rows.
- **List rows** (`GuideListFrame.lua:403+`, `CraftRouteFrame.lua:443-499`):
  - Rows are Buttons with a `HIGHLIGHT`-layer `solid` texture at white 0.04-0.06 alpha, so hover is free and needs no script.
  - Selection is a `tabbg` fill plus a 3px accent bar on the left (`MarkSelection`, `GuideListFrame.lua:372`).
  - Hover reveals extra row actions (star, open arrow) and re-flows the text's right edge (`ShowHover`, `:355-370`).
  - Typical two-line price row (`CraftRouteFrame`):
    - top line: accent display "band" on the left, body name in the middle, gold count on the right
    - bottom line: dim body-10 materials text on the left and spend on the right
  - Wheel scrolling is enabled on the rows too.
- **Event throttle pattern** (`MaterialsFrame.lua:183-196`): `BAG_UPDATE` only sets `dirty`; an `OnUpdate` repaints at most every 0.25s, and only while the window is visible.

## 3. Controls (all in `Theme.lua`, the reusable widget factory)

Every factory returns a frame with extra methods. State is drawn by re-tinting masks rather than swapping textures. Common methods are `SetOn`/`IsOn`, `SetActive`, `SetLocked(locked)` (alpha 0.45 + Disable) and `Fit(width)` (returns height).

- **Switch (toggle)**, `Theme:Switch(parent, label, onChange)`, `:1171-1241`:
  - The row is a Button 22px tall: a 36×20 `switch-track` and a 16px `circle-fill` knob.
  - The knob sits at x=2 when off and x=18 when on.
  - Off: track `text` at 0.10, white knob. On: track `switchOn`, knob near-black.
  - There is an optional red/green mode.
  - The label is body 13, 9px right of the track.
  - `Fit(w)` wraps a long label and counts lines from `GetStringWidth` (`lines * 15 + 4`), because a wrapped font string's own height is unreliable on 1.12.
  - The whole row is clickable.
- **Checkbox**, `Theme:Checkbox`, `:1248-1304`:
  - A 16px `solid` edge with a 14px inner fill and a 12px `tick` glyph.
  - Off: edge `subtle`, fill `panel2`, tick hidden. On: edge `accent`, fill `switchOn`, tick shown.
  - Grids are laid out two to a row, 170px apart and 26px row height (`OptionsFrame.lua:393-417`).
- **Step check (round)**, `Theme:StepCheck`, `:584-636`: a real `CheckButton` with `SetChecked`/`GetChecked` shadowed. It draws a `circle-border` ring (`subtle`, accent when checked) and a `circle-fill` accent fill.
- **Slider**, `Theme:Slider(parent,label,lo,hi,step,onChange,format)`, `:1310-1391`:
  - A 38px row: label top-left (body 13), value top-right (body 13, accent), and a horizontal `Slider` beneath.
  - The track is a 4px `solid` at `text` 0.14; the thumb is a 14px accent `circle-fill`.
  - Values snap to `step`.
  - **It reports only on mouse release**, while the displayed number follows live. This avoids feedback loops when the change rescales the window the slider sits in.
  - `row:SetValue` sets the value quietly, without firing `onChange`.
  - Percent formatter: `string.format("%d%%", math.floor(v*100+0.5))`.
- **Dropdown**, `Theme:Dropdown(parent,width,onSelect)`, `:1401-1487`:
  - The face is a 30px button with a `panel2` `tabFill` nine-slice and border, body-13 text and a 10px `caretDown` glyph that turns accent on hover.
  - The **list is parented to UIParent at `FULLSCREEN_DIALOG`** so a scroll frame cannot clip or overdraw it.
  - Rows are 22px and recycled. Each has a HIGHLIGHT wash at 0.06; the selected row's text is accent.
  - API: `SetItems({ {value,label}, ... })`, `SetValue`, `GetValue`.
  - The list closes on the button's `OnHide`. The owning window also closes all its dropdown lists on page change and `OnHide` (`OptionsFrame.lua:1260, 1304`).
  - There is no `UIDropDownMenu` anywhere.
- **Edit boxes**:
  - The search field (`GuideListFrame.lua:211-238`):
    - `EditBox`, 26px tall, `SetAutoFocus(false)`, `SetTextInsets(24,6,0,0)`
    - `panel2` `tabFill` with a `subtle` border, a 12px magnifier glyph and grey placeholder text that hides on focus or when text is present
    - Escape clears and drops focus; Enter drops focus; `OnHide` clears focus.
  - The numeric field (`GearFrame.lua:51-75`): a `solid` edge at white 0.22 behind a black (0.85) inset bg, with text insets 6. On commit it does `tonumber(GetText())`, and reverts if the text is not a number.
- **Buttons**:
  - `Theme:Pill` (`:639-666`): uppercase display 11, `panel3` fill, `SetActive` gives an accent fill with dark text.
  - `Theme:PanelButton(parent,label,w,h)` (`:675-693`): a Pill with hover (fill `tabbg`, text white) plus `SetText`/`GetText` shims, so it can replace `UIPanelButtonTemplate`.
  - `GlyphButton` (`:899-925`): a bare icon that turns accent on hover.
  - `ChipButton` (`:933-969`): a bordered square icon button with an `active` state (accent fill, dark glyph).
  - `Theme:Chip` (`:799-860`): a two-line toggle tile, code plus name.
  - `Theme:Badge` (`:766-790`): a 12px coloured tag with auto width.
- **Progress bar**, `Theme:ProgressBar`, `:550-577`: a real `StatusBar`, which avoids width-measurement bugs, over a black 0.4 track.
- **Scrollbar**, `Theme:ScrollBar(parent,width)`, `:1043-1099`:
  - A vertical `Slider` with a 10px track (black 0.35), a stadium thumb 28px tall tinted `subtle`, and caret-up/down `GlyphButton`s outside the ends.
  - `Nudge(delta)` moves by a step.
  - The carets dim to `border` colour at the ends of the range.
- **Popup menu (≡)** (`ObjectivesFrame.lua:319-461`):
  - The menu is a data table of `{label, glyph, key?, run}` entries, with `"-"` as a separator.
  - The frame is parented to UIParent at FULLSCREEN_DIALOG, `Panel(panel2)`, 220px wide with 28px rows.
  - Each row has a glyph, a body-13 label, a HIGHLIGHT wash and an optional tick box on the right for toggle items.
  - The menu is added to `UISpecialFrames` so Escape closes it.
- **Colour pickers: none.** Colour choice is by theme dropdown only.
- **Tooltip**, `Theme:ShowTip(owner, side, text, detail, color)`, `:1548-1697`:
  - A custom single frame, not GameTooltip. It uses `TOOLTIP` strata and `Panel(panel2)`.
  - Title is body 12 in `text`; detail lines are body 11 in `textDim`. Padding is 8, line gap 3, maximum width 260.
  - It anchors TOP, BOTTOM, LEFT or RIGHT of the owner. With `TipOutside(window)` it opens beside the window instead.
  - It auto-hides when its owner is no longer visible (`OnUpdate` check).
  - `HideTip(owner)` hides only if that owner is the one showing.
  - GameTooltip is kept only for real item links.

## 4. Options panel and persistence

- **Structure** (`OptionsFrame.lua:580-1263`): `AegisPathfinderOptions`, 546×560, DIALOG strata, opened beside the main window.
  - Left: the nav list of pages. Right: one shared `ScrollFrame` whose child holds every page as a hidden `body`; `ShowConfigPage(name)` shows one (`:1293-1310`).
  - Pages: Route, Dungeons, Filters, Appearance, Step Display, Automation, Action Buttons, Navigation, Maps, Gear, Item Score (as a sub-page), Extras, Maintenance, About.
- **Layout kit** (`:653-712`): a running `y` cursor with these helpers:
  - `page(name, sub)`
  - `place(region, heightOrFn, gap, indent)`: records into `body.flow` so the page can `Reflow` at a new width (`:135-150`)
  - `space(n)`
  - `section(title)`: `Theme:SectionHeader`, 12px accent uppercase with a 1px rule (`Theme.lua:1111`)
  - `note(text)`: `FinePrint`, body 11 dim, wrapping
  - `wide(dropdown)`
  - `stretchy(fitFn)`: callbacks run when the width changes
  
  The kit is handed to `Build.*` page builders that live **outside** the big function, to stay under Lua 5.0's 32-upvalue limit (`:181-187`).
- **Setting-bound builders** (`:197-485`):
  - `Build.CharSwitch(k, key, label, after, {parent=, defaultOn=, profile=})` writes `db.char[key]` or `db.profile[key]` and registers the switch in `frame.switches` / `pswitches`.
  - `opts.parent` indents the switch 24px and *holds* it (locked at 0.45) while the parent setting is off.
  - Similar builders: `Build.Slider` (percent), `Build.CharDropdown` (13px label above a full-width dropdown), `Build.ProfileDropdown` (label beside a 140px dropdown), `Build.Boxes` (checkbox grid), and `Build.Hold(row, held)`.
- **One refresh function**, `RefreshConfigPanel` (`:1383-1533`):
  - It is called on show and after any change with side effects.
  - It loops `frame.switches` and `pswitches` to `SetOn` from the db, honouring `defaultOn` with `db[key] ~= false`, then applies sub-switch locks.
  - Controls never hold state of their own; the db is the source of truth.
- **SavedVariables**: `## SavedVariables: AegisPathfinderDB` (plus a legacy name kept for migration); there are no PerCharacter variables. AceDB-2.0 provides `db.char` (per-character settings, with defaults from `RegisterDefaults("char", defaults)`, `Core.lua:95-205, 635-636`) and `db.profile` (UI layout: positions, sizes, theme, scale, opacity, minimap angle).
  - Missing nested defaults are back-filled by hand (`Core.lua:643-654`).
  - The theme, scale and switch colours are applied in `OnInitialize` before the first paint (`Core.lua:639-641`).
- Opacity: the guide's "Transparency" tints only the panel fill's alpha, so text stays solid (`ObjectivesFrame.lua:353-359`).

## 5. Minimap button, slash commands, tooltips

- **Minimap button** (`MinimapButton.lua:1-119`):
  - A 26px `Button` on `Minimap` at `MEDIUM` strata, level +8. Its icon is a full-colour logo TGA with no Blizzard border.
  - Hover shows an accent `circle-border` ring, 2px outset.
  - Left click toggles the main window; right click toggles options (`RegisterForClicks("LeftButtonUp","RightButtonUp")`).
  - Dragging installs an `OnUpdate` that computes `math.deg(math.atan2(cy/scale - my, cx/scale - mx))` and places the button at `cos/sin * 80` from the minimap centre. The angle is saved in `db.profile.minimapangle` (default 215°).
  - Mouse-down nudges the icon by (1,-1) for a pressed look.
  - Its tooltip uses `Theme:ShowTip(this,"LEFT", "Name vX", {"Click…","Right-click…","Drag…"})`.
  - A setting hides the button.
- **Slash commands** (`Core.lua:207-610, 657-673`):
  - `RegisterChatCommand({"/apg","/pathfinder"}, options, "AEGISPATHFINDER")` registers an AceConsole options table of `execute`, `toggle` and `text` args.
  - The handler is given an explicit name so it can be wrapped: a bare `/apg` toggles the main window instead of printing AceConsole's help.
  - They avoided `/aegis` because another suite addon uses it.
- **Control tooltips**: the pattern below. For PanelButtons, the existing hover script is captured with `GetScript` and chained:
  ```lua
  local enter, leave = btn:GetScript("OnEnter"), btn:GetScript("OnLeave")
  btn:SetScript("OnEnter", function() enter(); Theme:ShowTip(this, "BOTTOM", "Title", {"detail…"}) end)
  btn:SetScript("OnLeave", function() leave(); Theme:HideTip(this) end)
  ```
  (`MaterialsFrame.lua:130-157`.) Locked ("coming soon") rows still show a tip (`GuideListFrame.lua:292-297`).

## 6. 1.12 / Lua 5.0 workarounds

- **No `SetColorTexture`**: use `SetTexture(solid.tga)` + `SetVertexColor(r,g,b,a)` everywhere (`Theme:Strip`, `Divider`, row fills).
- **No rounded rects, no clipping**:
  - `Theme:NineSlice` (`Theme.lua:419-480`) builds four fixed corners, four stretching edges and a centre from one 32px mask via `SetTexCoord`. The slices are 10/32 and 22/32.
  - `CapStrip` uses one-side-rounded masks because `overflow:hidden` does not exist.
- **Shadow drawing order**: textures within one draw layer have no defined order, so the shadow must be a ring with a clear middle (`Theme.lua:484-493`; the build fails otherwise).
- **No `SetRotation`**: use the 8-argument `SetTexCoord` to rotate a quad (`docs/UI_SPEC.md:106-111`).
- **No runtime gradients**: they are baked into textures. **No letter-spacing**: the wordmark is pre-rendered. **No emoji or symbols in the font**: use glyph textures.
- **Wrapped `FontString:GetHeight()` is unreliable**: compute lines from `GetStringWidth()/width` (`Theme.lua:1221-1231`, `OptionsFrame.lua:127-131`, tooltip fallback at `:1673`).
- **StatusBar instead of measured texture widths** for progress (`Theme.lua:541-549`).
- **`StartSizing` re-anchors frames** and two anchors break `SetHeight`. Fixes: a custom grip, plus `AnchorTopLeft` after every move.
- **Frame-level interleaving between windows**: the banded restack (see §2).
- **Lua 5.0 idioms**:
  - event handlers use globals `this` and `arg1`
  - `table.getn` instead of `#`
  - `math.mod`, not `%` or `math.fmod`
  - `string.gfind`, not `gmatch`
  - `string.find` with captures, not `match`
  - no `select('#')`
  - a maximum of 32 upvalues per function, which is why page builders are split out
  
  `Tools/verify.py:83-95, 483-507` enforces these with regexes and with `luac -l`.
- A dropdown list inside a scroll frame must live outside it, on UIParent at `FULLSCREEN_DIALOG`.
- `SetFont` returns false for a bad TTF, which is how the font fallback works.
- AH querying rules (`CraftScan.lua:11-23`): call `CanSendAuctionQuery()` before every query; pass strings for the name and level args of `QueryAuctionItems` and nil for the rest; pages count from 0 with 50 per page; read `AUCTION_ITEM_LIST_UPDATE` only while a reply is awaited; and keep only exact-name matches.
- Money formatting: `FormatCopper` (`CraftRouteFrame.lua:44-60`) produces "12g 4s 97c", omits zero units and drops copper above 100g. It uses `math.mod`.

## 7. Top 10 reusable UI patterns (ranked)

1. **Tinted white-mask nine-slice: `NineSlice` + `Panel`.**
   - Ship 32×32 white rounded-rect fill and border TGAs with a 10px corner. Create nine textures with `SetTexCoord`:
     - corners: `{0,S0,0,S0}` etc.
     - edges: stretched along one axis
     - centre: stretched both ways
     - `S0 = 10/32`, `S1 = 22/32`
   - Corners are fixed at 10px. Edges anchor corner to corner.
   - Every piece goes through `Tint(tex, colorName, alpha)`. Return a table with `SetTint`.
   - A panel is three layers: the shadow ring (black 0.62, 7px outset, no centre), the fill, then the border. This one primitive drives panels, buttons, tabs, dropdowns and fields.
2. **Palette tokens and live theme swap.**
   - Keep `Theme.color` as `{r,g,b}` tables built from hex.
   - Every tint goes through `Tint` or `TextColor`, which record `obj -> colourName` in weak-keyed tables.
   - `ApplyTheme` mutates the colour tables in place, then re-applies the colour to every recorded object.
   - Store the theme key in `db.profile`; apply it in `OnInitialize`.
3. **One-call window chrome (`Chrome`).**
   - Header: 30px, `panel2`, rounded top cap, 1px divider, title or wordmark. Optional left chip; close chip on the right, 8px in.
   - Optional subhead: 18px `tabbg` strip with a 10px uppercase dim label.
   - The header is the drag handle, then `AnchorTopLeft`, then save.
   - Register for stacking, scaling and clamping. Add the frame name to `UISpecialFrames`. Fade in over 0.5s on show.
4. **Position persistence + smart default placement.** On show, `RestorePosition(key)`; failing that, dock beside the main window on the side facing screen centre. Save `point`, `rel`, `x` and `y` after a drag. Provide a "reset windows" command.
5. **Switch row (`Theme:Switch`).**
   - A whole-row Button: 36×20 stadium track and a 16px knob at x=2 (off) or x=18 (on), with a body-13 label.
   - The `onChange(on)` callback writes the db.
   - `SetLocked` sets alpha 0.45 and Disable. `Fit(w)` wraps the label using the line-count heuristic.
   - Nested settings are indented 24px and held while the parent is off.
6. **Themed dropdown (`Theme:Dropdown`).**
   - Face: a 30px `panel2` rounded face with text and a caret.
